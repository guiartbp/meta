# META — Poli

Sistema de missões diárias, XP, níveis e recompensas para estudar para as provas.
Página única (sem servidor, sem conta). Os dados ficam no navegador do aparelho; use **Mais → Exportar backup** toda semana.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `meta`) e envie todos os arquivos desta pasta para a raiz.
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, pasta `/ (root)`.
3. Abra `https://SEU-USUARIO.github.io/meta/` no celular e use "Adicionar à tela inicial".
